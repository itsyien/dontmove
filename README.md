# 请勿搬动 · The Extra Floor

五层老公寓的第一人称恐怖逃生游戏。唯一目标：下到一楼，走出外门。所有场景由程序几何搭建，未使用网络场景照片。

## 游玩

在线游玩：<https://itsyien.github.io/dontmove/>。推荐桌面 Chrome / Edge 与键盘鼠标。

本地开发需要 Node.js 24：运行 `npm ci`，然后 `npm run dev`，访问终端显示的地址。`npm test` 运行回归测试，`npm run build` 构建 Pages 版本，`npm run preview` 在本地预览 `/dontmove/`。不能直接双击 HTML。

`main` 保存源码，`gh-pages` 保存构建产物，GitHub Pages 从 `gh-pages` 根目录发布。更新游戏时需先测试和构建，再更新发布分支；仅推送源码不会改变线上版本。本地备份、原始素材、开发预览稿和机器专用配置不上传。

| 操作 | 按键 |
|---|---|
| 移动 / 快走 | WASD / Shift |
| 观察 | 鼠标；无法锁定时按住拖动，或用方向键 |
| 门、开关、电视、窗帘、观察窗、柜门 | 对准目标按 E |
| 暂停 / 恢复 | Esc |
| 环境声音 | M |

首次默认英文。主菜单右上角或暂停菜单可切换 English / 中文，选择会保存；切换不重置当前游戏。菜单中可调画质、音量、灵敏度、镜头起伏及“减少闪烁”。声音不是解题条件。

地上的旧照片是出口线索：沿途位置、角度随本局种子变化，转角处有引导。无需收集或按 E，跟着痕迹前进即可找到各层出口；检查点重试保留照片位置。

## 当前版本

- 五楼住区、四楼公共生活区、三楼画像资料区、二楼过亮活动厅、一楼空门厅。每层有绕路空间、功能陈设和可选交互；全楼共 28 幅可发现画像。
- 双跑楼梯在遮挡转角衔接，玩家高度和视角连续。门扇保持侧边铰链，碰撞与动画一致，外门朝室外开启。
- 查房者：先给反应时间，再进行两次各 3 秒的静止检查；可以转头。一旦发现移动，立即提示，0.5 秒后仍在移动就抓捕；及时停住后，整次查房不再允许移动；再次移动立即抓捕，转头不受影响。
- 奶娃：观察时停止，离开视野 0.6 秒后才移动；凝视不能防止贴身抓捕。看着它后退，再绕过墙体继续撤离。它需要实际检查两个可达位置并失去踪迹才会离开。
- 坤坤：跑得比玩家快。可以按 E 躲入沿路衣柜，等待柜外搜寻 6 秒和撤离 2.5 秒；过早出来会恢复追逐。木门争取撤离时间，防火门挡住冲撞；冲木门前检查第二出口并给出至少 4 秒、包含撤离余量的提示。
- 普通房间不会直接清除追击。进入下一层时清除上一层遭遇，并重新安排该层角色计时。
- 检查点为五、三、一楼。还在被追踪时显示“尚未脱险”；脱险才保存。失败恢复当前区块及相同异常次序，单独“重新开始一整局”才换种子。
- 局部故障灯、电视静帧、黑白照片、窗后人影、无人观察才转向的奶蛙石膏像与背带裤模特。抓捕有对应角色的近景，不混用统一惊吓头像。

操作过的门、灯和陈设状态会持续到检查点重置。本版不使用旧西装孙笑川；灭霸暂不接入。保留已接受的角色抠图；雨姐抓捕近景使用单独修复的高清衍生图，原图仍保留。

## 角色与应对

常规遭遇按行进进度触发，同一时间只有一组危险角色。汪精卫、雨姐可在同层多轮间隔出现，不受常规遭遇次数上限约束。五楼预设查房者、奶娃，四楼预设坤坤、奶娃；三楼预设良子、奶娃，一至二楼由本局种子选取。若仍在追踪或冷却中，会延后，快速通过楼层也可能跳过该层的预设。失败重试沿用种子。

| 角色 | 出现条件 | 应对 |
|---|---|---|
| 孙笑川 / 查房者 | 五楼前段；低楼层也可能遇到，灯光压暗开始查房 | 停止移动，可以转头；等两轮各 3 秒检查及退场，中间停顿不算安全 |
| 奶娃 / 偷步者 | 五、四楼后段；低楼层也可能遇到 | 看着它后退，别碰它；绕过实体墙并拉开距离，进普通房间或关门不会直接脱险；换层会刷新遭遇 |
| 坤坤 / 借路者 | 四楼前段预设；四楼与一楼每次退场后约 30 秒返回；二楼禁止出现 | 靠近衣柜按 E 躲入，等搜寻与撤离完成后再按 E 出来；或利用木门拖延、防火门阻挡后绕路 |
| 良子 / 播报者 | 三楼首场预设；一、二楼也可能选中。靠近可见的电视后自行亮屏 | 3 秒预警后开始限时；拿到电视旁与稍远处的两个遥控器，再返回电视按 E 关闭。遥控器始终透视标记，靠近按 E 拾取。转身或静止不再解除遭遇。 |
| 汪精卫 / 巡楼者 | 一、二楼间隔出现，先红灯与 7 秒倒计时 | 找门扇上的蒋介石画像，进入后关好全部门；或躲进同样画像标记的衣柜。普通门与未标记衣柜无效，出现时立即检查；等离场后再出来。 |
| 东北雨姐 / 来访者 | 三楼及以下间隔出现，每次最多三个随机静止分身，先文字与冷光预告 | 看见任一分身每秒掉 44 点理智；多分身不叠加。低头或完全移开视线即停止；两秒后每秒恢复 6 点。清零触发专属近景。 |
| 汪精卫画像 | 每层两幅装框画像，另有窗后人影 | 画像本身非致死，可按 E 发现计分 |
| 牢大、蒋介石、孙笑川壁画 | 分布五层，三楼更集中，交互后有画框变化 | 首次查看每个画框 +100 分；非致死，不是必做任务 |
| 奶蛙石膏像、背带裤模特 | 固定陈设；无人注视时可能转向 | 非致死，不是追击角色 |

本次修复：旋转门采用与门扇方向一致的碰撞；被身体挡住时暂停、退开后继续，E 可反向操作。楼梯保留相连两层，补齐平台边界并统一模型、通行与视线遮挡。转角暖灯、磨亮地砖及楼梯间文字代替场景箭头。

## 一、二楼巡楼遭遇（2026-11-15）

汪精卫现在也会作为巡楼者攻击，原画像继续保留。进入低层后约 10–12 秒开始尝试安排第一次巡查；巡查结束后间隔 28–38 个安全秒再来。楼梯通行、其他威胁正在活动、或附近没有可达的可靠遮挡时会延后，不叠加怪物。

走廊灯变红后有固定 7 秒：寻找蒋介石画像标记的门或衣柜。进入标记房间并关好全部门，或按 E 躲进标记衣柜，才不会被发现。未标记的门、柜子、墙后遮挡和距离均无保护，巡楼开始时立即检查并抓捕。退场后有提示，仍需复位两个不同开关恢复照明。一楼后续安排棍母，见下节。

外门打开后走过室外门槛即可通关，无须先摆脱任何怪物；越过出口的当帧优先结算逃生。


## 东北雨姐与理智（2026-11-15）

从三楼开始，在三、二、一楼的可通行位置随机出现。位置和次数由本局种子决定，检查点重试可复现；不会与其他遭遇叠加。正常形态使用 dongbeiyubigfeet.png，理智归零时单独使用 dongbeiyubaifang-shadow.png 的脸部近景：基于高清版做局部压暗、自然眼窝与脸侧阴影，保留原表情，不加红眼或血腥。原图及之前的高清版保留。

现身前有三秒文字和冷白灯压暗预警；预警期间不显示人物、不扣理智。她现身后原地不动，处于可见范围且没有实体遮挡时，理智每秒减少 44，满值约 2.27 秒耗尽。低头、转身将她完全移出画面，或绕到墙后，会立即停止消耗；两秒后每秒恢复 6。理智随检查点保存。现身约 22 秒后退去，灯色恢复；下一次来访间隔 35–50 个安全秒，位置无法安全容纳人物时会延后或取消该次来访。

预警为持续渐变而非快速频闪，减少闪烁设置下仍保留同样信息。实时局部光源数量维持五盏加手电。

## 安全调试模式（2026-11-15）

打开 http://127.0.0.1:5178/?debug 。右侧面板点击 5F–1F 即可切换到该层主通道，保持当前种子和场景交互状态，清除正在进行的遭遇与楼梯切换状态。调试不会强制改写普通模式设置，也不会自动跳过关闭的门。

默认免死，正常显示角色图片和 jumpscare；每次遭遇首次抓捕播放惊吓后继续调试，不进入死亡界面。透视线框叠加显示；透视打开时，线框和名称可穿过墙体显示。实际遭遇算法、视线判定和理智消耗继续运行，抓捕仅记录为“已拦截抓捕”。“明亮环境”会提高照明、减少雾、关闭灯闪与危险变色、电视异常、装置转向和环境低鸣。关闭明亮环境可检查原灯光，但免死仍然保持。

面板显示楼层、种子、坐标、上下楼阶段、理智、检查点、角色阶段和位置、巡楼/来访倒计时、最近门开度和受阻状态、抓捕记录、帧率、绘制次数及三角形数；支持收起和清除遭遇。普通游戏使用不带 debug 的链接。旧的 ?qa&debug 仍是开发回归工具，保留真实伤害规则；不要把它当作安全游玩入口。

楼梯门口已扩大平台至覆盖完整门洞，并同步修正平台地面、顶面、后墙与通行边界。玩家只能从有效通路进入楼梯状态，返回走廊时也使用正确区域判定，避免贴门框卡死。关闭的门、护栏和中间墙仍然有碰撞。

## 循环巡楼与雨姐三分身

同层可多轮遇到汪精卫和雨姐：巡楼结束后等待 28–38 个安全秒，来访结束后等待 35–50 个安全秒；其他遭遇与楼梯通行会延后计时，不叠加两种冲突的应对要求。
